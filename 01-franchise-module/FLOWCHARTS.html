0 — Naming Convention (pehle ye samjho)

Tiers (upar se neeche)

WH = Warehouse (top) MW = Mini-Warehouse (optional) Level 1 shop Level 2 shop Level 3 shop User

Shop naming — L2 aur L3 DONO L1 ke child

NameLevelKiska child
S3Level 1Warehouse / Mini-WH ke under
S3.1Level 2S3 ka child
S3.2Level 3S3 ka child (S3.1 ka nahi)
⚠️ Ye structure badal gaya hai. Pehle chain seedhi thi — S3 → S3.1 → S3.1.1 (L3, L2 ke neeche).
Ab: S3.1 (L2) aur S3.2 (L3) dono seedha S3 (L1) ke neeche — aapas me bhai-bhai, ek doosre ke neeche nahi.
Mini-Warehouse bhi ek tier hai (alag level). Multiple ho sakte → MW1, MW2...
Chain: WH → MW → Level 1 → (Level 2 ya Level 3) → User
Ek hi chain me L1+L2+L3 teeno kabhi nahi aate.

5.5 Commission split — har level ko apna

flowchart LR WH["🏭 WH"]:::wh -->|maal| L1["Level 1
💰 apna set commission"]:::l1 L1 -->|maal| L2["Level 2
💰 apna set commission"]:::l2 L1 -->|maal| L3["Level 3

Rule: L2 aur L3 ke beech koi rishta nahi. Baaki flow bilkul pehle jaisa — har level ko apna set commission milta hai.
• Sale L2 se → L1 aur L2 ko apna-apna
• Sale L3 se → L1 aur L3 ko apna-apna
Ek raaste ka level doosre raaste me aata hi nahi, isliye aapas me kuch bantta bhi nahi.
Commission ka number product master se aata hai — Admin har product pe har level ka rate set karta hai. System me koi fix ladder hardcode nahi hai.
❌ Purana "missing level ka roll-up" rule ab KHATAM hai. L2 aur L3 alag branch hain — ek ka na hona doosre ko affect hi nahi karta.
